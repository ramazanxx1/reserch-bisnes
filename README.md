# Конкуренты рядом

Рабочий веб-прототип: адрес или точка на карте → категория → радиус → реальные организации OpenStreetMap. Регистрация и платежи в приложении отсутствуют. Интерфейс на русском, на телефоне карта и список переключаются вкладками.

## Запуск

Требуются Node.js 22.13+ (рекомендуется 22 LTS или новее), npm и интернет.

```bash
npm ci
npm run dev
```

Откройте локальный URL из терминала. Для проверки и production-сборки:

```bash
npm test
npx tsc --noEmit
npm run build
npm start
```

Стек: React 19, TypeScript, Vinext/Vite (совместимые с Next.js маршруты), Leaflet 1.9.4, CSS, компоненты Radix/Shadcn. Серверный маршрут проксирует поиск адресов Photon; организации браузер получает напрямую из Overpass по HTTPS с CORS. Production-сборка совместима с Cloudflare Workers. База данных не требуется.

API-ключи не нужны. Опциональные настройки перечислены в `.env.example`; копируйте в `.env` для локальной разработки. URL поставщиков задаются в конфигурации сервера; `/api/sources` передает браузеру публичный адрес Overpass, который должен поддерживать CORS. Секреты в этом маршруте недопустимы. Для облачной версии используются переменные окружения хостинга.

### Что используется в прототипе

1. Организации — Overpass, публичный сервер VK Maps `https://maps.mail.ru/osm/tools/overpass/api/interpreter`, указанный в каталоге OSM с глобальным покрытием. При проверке основной `overpass-api.de` возвращал 406/504; автоматического переключения или циклических повторов нет. Сервер меняется через `OVERPASS_URL`. Прототип делает только ручные запросы, ограничивает радиус, кэширует успешные ответы. Для массового или коммерческого запуска нужен собственный сервер либо согласованный поставщик.
2. Адреса — [Photon](https://github.com/komoot/photon), публичный сервер Komoot с данными OSM. Ключ не требуется, оператор допускает разумное число запросов, может ограничить доступ и не гарантирует доступность. Поиск запускается кнопкой лупы или Enter, не на каждое нажатие клавиши. Поиск по русским адресам иногда неоднозначен: выбирайте точный вариант из списка или точку на карте.
3. Подложка — стандартные тайлы OSM. Соблюдается [Tile Usage Policy](https://operations.osmfoundation.org/policies/tiles/): видимая атрибуция, стандартное браузерное кэширование, нет офлайн-скачивания или массовой предзагрузки. При нагрузке замените подложку на подходящего провайдера.
4. Публичный Nominatim намеренно не встроен. Его [Usage Policy](https://operations.osmfoundation.org/policies/nominatim/) ограничивает суммарный трафик приложения до 1 запроса/сек, запрещает autocomplete и отдельно ограничивает автоматическое встраивание универсального геопоиска в no-code/AI-платформах; требует осознанного решения и ответственности разработчика. Photon — отдельный сервис со своей политикой.

## Как определяется похожий бизнес

Это категориальное сопоставление, а не оценка экономической конкуренции. Русские названия и близкие форматы сведены к наборам тегов в `lib/geo.ts`:

| Выбор | Теги OSM |
| --- | --- |
| Кофейня | `amenity=cafe`; также `amenity=fast_food` + `cuisine=coffee_shop` (в том числе среди значений через `;`). Кафе шире кофеен, возможны смежные форматы; в карточке обычное `amenity=cafe` подписано «Кафе», а явный `cuisine=coffee_shop` — «Кофейня» / «Кофе навынос». |
| Пекарня / булочная | `shop=bakery` |
| Продуктовый магазин / супермаркет / магазин у дома | `shop=supermarket`, `convenience`, `grocery` |
| Барбершоп / мужская парикмахерская | `shop=hairdresser` + `hairdresser=barber`; либо `male=yes` + `female=no`; либо слово barber/барбер в названии парикмахерской |
| Аптека | `amenity=pharmacy` или `healthcare=pharmacy` |
| Автомойка / самообслуживание | `amenity=car_wash` |

Магазины кофе `shop=coffee` не включены в кофейни: они могут продавать только зерно. Рестораны автоматически не добавляются. [Описание кафе в OSM](https://wiki.openstreetmap.org/wiki/Tag:amenity=cafe), [описание парикмахерских](https://wiki.openstreetmap.org/wiki/Tag:shop=hairdresser).

## Геометрия и дубли

- Overpass запрашивает nodes, ways и relations. Для площадных объектов использует `out center`: это центр bounding box, не вход в здание.
- Затем Haversine с радиусом Земли 6 371 008,8 м вычисляет расстояние по прямой. Фильтрация по точному значению `distance <= radius` выполняется до округления. Результаты сортируются по этому же значению.
- Повтор одного `type/id` исключается. Дубли разных представлений объединяются консервативно: совпавшее нормализованное название, близость до 35 м, согласованный адрес/телефон или почти совпавшие координаты node/way. Различающиеся branch/ref, этаж, помещение, улица или номер дома препятствуют объединению. Все исходные ID сохраняются в `sourceIds`.
- Общее название сети или общий сайт сами по себе не являются основанием для объединения. Филиалы по разным адресам сохраняются. Без уникальных идентификаторов OSM абсолютное распознавание дублей невозможно: эвристика может оставить сложные дубли или объединить неразличимые записи.
- Явно помеченные закрытые/заброшенные объекты исключаются, но актуальность бизнеса не гарантирована.

## Состояния и ограничения

- Радиус по умолчанию 1 км; варианты 500 м, 1 км, 2 км и целое значение 100–5 000 м. Ограничение защищает публичный API.
- Любое изменение параметров отменяет ожидающий клиентский запрос и очищает прежние результаты. Ответ отмененного запроса не заменяет текущий поиск.
- Поиск организаций проверяет параметры, кэширует успешные ответы на 5 минут (до 30 записей) в текущей вкладке, выдерживает интервал не менее 2,5 секунды и паузу 30 секунд после 429/406. Адресный прокси имеет отдельный кэш 24 часа / 100 записей и ограничитель в пределах Worker isolate. Это не распределенная защита от нагрузки; для масштабирования нужен согласованный провайдер, общий лимитер и кэш.
- Ошибки сети, 429, 5xx, timeout, неверный JSON и частичный ответ Overpass с `remark` дают ошибку. Нет fallback на вымышленные организации или встроенного demo-набора.
- Пустой успешный ответ: «В выбранном источнике не найдено похожих предприятий». Это не утверждение об отсутствии конкурентов.
- Недостающий адрес обозначается явно; сайт и часы работы не выдумываются. `opening_hours` показаны как исходная запись OSM; «открыто сейчас» не вычисляется.
- Карточки и маркеры связаны; клик по карточке выбирает маркер и открывает popup, на телефоне переключает на карту. Клик по карте задает точку; центральный маркер можно перетаскивать.
- Количество конкурентов ничего не говорит о прибыльности без оценки спроса, трафика, аренды и формата.
- Адреса/координаты отправляются поставщикам. В приложении нет аккаунтов, истории поисков или аналитики. Доступ к приватной размещенной копии отдельно регулируется хостингом Sites; локальный запуск не требует входа. Карта напрямую обращается к серверу тайлов OSM.

## Структура

- `app/page.tsx` — интерфейс и состояния запросов.
- `components/nearby-map.tsx` — карта, круг, маркеры и popup.
- `app/api/geocode/route.ts`, `app/api/sources/route.ts` — адресный прокси и конфигурация источника.
- `lib/search-client.ts` — прямой запрос браузера к Overpass, timeout, отмена, ограничения частоты и кэш.
- `lib/geo.ts` — категории, геометрия, нормализация, удаление дублей.
- `lib/upstream.ts` — timeout, проверка upstream и кэш.
- `tests/` — проверки геометрии, дублей, валидации и ошибок API. Искусственные записи есть только в unit-тестах, приложение их не импортирует.
- `TESTING.md` — результаты проверки живых запросов и интерфейса.
